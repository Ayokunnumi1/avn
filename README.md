# AVN — Digital Address Verification Network

**AI-assisted physical address verification for Nigeria (then Africa).** Institutions, individuals, approved local field verifiers and platform administrators work together in four installable PWAs on one shared backend:

| App | Port | Who | What |
|---|---|---|---|
| **User App** (`apps/applicant-web`) | 3000 | Applicants / individuals | Marketing site, phone-OTP sign-in, 9-step verification wizard with map pin, secure institution invitation links (no account needed), tracking timeline, payments, reports, disputes |
| **Agent App** (`apps/verifier-web`) | 3001 | Field verifiers | Mobile-first onboarding (photo, ID, selfie, payout account), on-duty switch with live location heartbeat, nearby job offers, navigation, arrival validation, in-app camera evidence, checklist, earnings & withdrawals |
| **Business App** (`apps/business-web`) | 3002 | Banks / organisations | Onboarding, dashboard, requests, bulk CSV, versioned policies, evidence & GPS review, PDF reports, billing wallet, team RBAC, API keys & signed webhooks, AI analytics assistant |
| **Admin Panel** (`apps/admin-web`) | 3003 | Platform operators | Overview, verifier & institution approval, assignment monitoring + live map + manual assignment, manual reviews, fraud, disputes, finance & payouts, pricing/config, geography, AI administration, audit log |
| **API** (`apps/api`) | 4000 | — | Express modular monolith, `/api/v1`, OpenAPI at **`/api/docs`** |
| **Worker** (`apps/worker`) | — | — | Separate BullMQ process: notifications, dispatch, webhooks, reports, AI, bulk, payouts + database-driven recovery sweep |

**How a verification works:** institution creates a request → applicant opens a secure SMS link, confirms with OTP and pins their exact property on a map → the assignment engine finds an **available, identity-approved verifier within 15 minutes' walk** (PostGIS + pedestrian routing; expands 15 → 20 → 30 → 45 min) → first to accept wins (atomic, concurrency-safe) → verifier walks there, records arrival (GPS + accuracy, 50 m threshold), captures camera-only photos (SHA-256 + perceptual hash), completes a structured checklist → a **deterministic, versioned rules engine** produces seven separate findings and an outcome (Verified / Partially verified / Not verified / Inconclusive / Manual review) → a signed PDF report is issued and pushed by webhook. AI only *assists* (photo-quality hints, address parsing, report wording, analytics intents) and never decides outcomes.

## Quick start (local)

Prerequisites: Node 22, pnpm 10, PostgreSQL 16 **with PostGIS**, Redis 7. (Or `docker compose up` — see below.)

```bash
cp .env.example .env
pnpm install
pnpm db:generate
pnpm db:deploy      # applies migrations (creates the postgis extension)
pnpm db:seed        # fictional demo data, generated by running real end-to-end flows
pnpm dev            # API + worker + all four apps
```

Open <http://localhost:3000> (User), <http://localhost:3001> (Agent), <http://localhost:3002> (Business), <http://localhost:3003> (Admin), <http://localhost:4000/api/docs> (API docs).

**Demo logins** (all fictional, password `AvnDemo2026!`):

| App | Accounts |
|---|---|
| Admin | `super@avn.local` · `ops@avn.local` · `reviewer@avn.local` · `finance@avn.local` |
| Business | `owner@demobank.test` · `officer@demobank.test` · `finance@demobank.test` · `auditor@demobank.test` · `owner@samplemfb.test` |
| Agent | `verifier01@avn.local` … `verifier16@avn.local` (approved) · `verifier17/18` (pending approval) |
| User | `applicant01@avn.local`, or phone OTP with `08010000001` (the dev OTP is shown on screen) |

To demo live dispatch without phones: `pnpm --filter @avn/api simulate:verifiers 8 --accept` keeps 8 seeded verifiers "on duty" through the real API (clearly labelled simulator).

Reset local data: `pnpm db:reset` (drops, re-migrates and reseeds — development only; the seed refuses `APP_ENV=production`).

### Docker

```bash
docker compose up -d postgres redis
docker compose --profile setup run --rm api-migrate
docker compose up --build
```

## Quality gates

```bash
pnpm typecheck   # strict TypeScript across 20 packages
pnpm lint        # ESLint incl. React Hooks rules
pnpm test        # 122 tests: unit + integration against real Postgres/PostGIS
pnpm build       # production builds of API, worker and the four PWAs
node e2e/full-flow.cjs   # browser E2E across all four apps (requires the running dev stack)
```
