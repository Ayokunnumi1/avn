# Changelog

## 0.1.0 — 2026-11-04 (MVP)

### Added
- Monorepo (pnpm + Turborepo) with strict TypeScript, ESLint and Vitest.
- PostgreSQL 16 + PostGIS schema (50+ models), generated geography columns, GiST indexes, partial unique index for single live assignment, append-only ledger trigger.
- Express API (`/api/v1`) with Zod-validated, auto-documented routes (OpenAPI at `/api/docs`).
- Authentication: phone OTP, email/password with lockout, TOTP MFA, per-app httpOnly sessions, CSRF header guard, password reset, guest invitation sessions.
- Assignment engine (PostGIS + pedestrian routing, 15/20/30/45-minute tiers, atomic acceptance, expiry and redispatch).
- Field visit workflow, camera evidence with integrity hashing and duplicate detection, deterministic verification engine `avn-rules@1.0.0`, manual review, disputes, signed PDF reports with public verification.
- Payments (Paystack + simulator), wallets, immutable ledger, payouts with finance approval, refunds, reconciliation, statements and invoices.
- Institution API keys, signed webhooks, bulk CSV, tenant-scoped analytics assistant.
- Optional AI layer (Anthropic adapter, budgets, usage tracking, deterministic fallbacks).
- BullMQ worker with database-driven recovery sweep.
- Four PWAs (User, Agent, Business, Admin) with shared design system, service workers, offline fallback, update prompts and install support.
- Seed data generated by running real end-to-end flows; 122 automated tests; browser E2E script; Dockerfiles, Docker Compose, CI and deployment docs.
